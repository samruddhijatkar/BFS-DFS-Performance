# Context Diagram

## System
BFS and DFS Graph Search / Path-Finding System

## External Actor

### User
The user provides:
- Graph
- Start node
- Goal node
- Search algorithm

### BFS/DFS Search System
The system performs graph searching using:
- Breadth-First Search (BFS)
- Depth-First Search (DFS)

### Search Result
The system returns:
- Path
- Nodes expanded
- Runtime

## Context Flow

User
↓
BFS/DFS Search System
↓
Search Result
